# Mushkil Asan Mobile

Expo + React Native MVP shell for the Mushkil Asan marketplace.

## Stack

- Expo SDK 54
- React Native
- TypeScript
- Expo Router

## Current Scope

- Two-mode role selection and onboarding placeholder
- Poster home, task posting stepper, and task/offers screen
- Job seeker jobs, offers, and earnings placeholders
- Shared task status timeline
- Profile and support/report flow
- Mock domain data for tasks, offers, job seekers, categories, and timeline events

## Run

```bash
npm start
```

Use Expo Go for the fastest local loop.

```bash
npm run android
npm run ios
npm run web
```

## Environment Notes

Node and npm are available on this machine. Java is currently missing, so Android emulator/native build workflows will need a JDK before `npm run android` can launch a local Android build. Expo Go can still be used for early UI iteration.

## Checks
